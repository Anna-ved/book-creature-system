Специальные операции над объектами

Все операции выполняются в виде хранимых функций PostgreSQL на стороне СУБД.

1. Рассчитать среднее значение attackLevel для всех существ

2. Сгруппировать объекты по значению attackLevel и вернуть количество

3. Количество существ, у которых кольцо меньше заданного веса

4. Найти персонажа с самым сильным кольцом

5. Уничтожить города эльфов

Удаляет города, у которых губернатором является эльф (ELF). Жители городов переселяются в безопасный город или удаляются.
